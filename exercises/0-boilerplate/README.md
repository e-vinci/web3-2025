# Boilerplate

This folder contains the boilerplate used for the exercise sessions. The boiler plates aims to provide a starting point for the exercises with the bare minimum to get started.

# Backend

A single file projet with a simple NodeJS express server in the file `app.ts`.

# Frontend

A single file projet with a simple react app hosted with vite. See the `frontend/README.md` file for more information. The project is the result of the initialization of a vite project with the command `npm create vite@latest`. Only two plugins were selected: react and react-swc.
